Names
PI Vision names an AF attribute Element|Attribute. On, the symbol shows only the part after the element, so K-302|Compression reads Compression: for a collection, where every copy is one asset's. PI point names are unchanged. Per-attribute settings (Data Health ranges) then match the shorter name.
Saving and data state
A button in the corner, shown when the pointer is over the symbol: the symbol as a PNG image, its drawing as SVG where it is one, or its data as CSV. Files are made in the browser; nothing is sent anywhere.
0 is off. Marks the symbol when the newest timestamp it was sent is older than this, so a frozen interface does not pass for a steady process. Not shown while the display is looking at the past.
Hides the symbol while none of its data sources has a good value, for a display shared by assets that do not all have every attribute. It comes back with the data.
A button, shown when the pointer is over the symbol, that trends its data sources in a panel you can drag and resize. The same button on another symbol adds its sources to the open trend. History is read from PI Web API, only when the button is pressed.
Time range
Off, the symbol follows the display's time range. On, it shows the range below and says so in a badge, whatever the display is set to. PI Vision cannot send a symbol a range of its own, so the values are recorded values read from PI Web API; without it the symbol keeps the display's range and the badge says the setting is not in force.
PI time: *-30d, t (today at midnight), y (yesterday), * (now), or a date and time.
Read again only while the range ends at now. The badge says when a source hit the limit or could not be read.
