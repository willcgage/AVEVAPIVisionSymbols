Rows from an AF search
An AF search finds the assets for itself, so a fourteenth compressor appears without the display being edited. The data source dropped on the symbol then only places it and gives the search a starting point. It reads through PI Web API; a badge on the symbol says how many assets it found and names any asset without the attribute.
Used when the display was opened without an asset, so the same display follows whichever area it is opened on. Left blank, the element of the attribute dropped onto the symbol is the root.
Current values, or the statistic this symbol is set to over the display's time range (its own range, when it has one). The search itself is asked again only when what it searches for changes.
