PI Web API connectivity check

Run this from the PI Vision server, in a browser, as a normal user — that is the only place the real conditions exist. It reproduces exactly what a PVX symbol does, and reports which configuration actually works on your network rather than which one should.

Settings

Include /piwebapi, no trailing slash. The hostname must match the certificate.
Enables the Event Frame test.
Not PI Vision's session token — with OIDC, PI Vision talks to its backends using its own Process Identity and never hands the user's token to display code.

Results

Part of the PVX symbol library. Nothing here writes to PI — every request is a read.
