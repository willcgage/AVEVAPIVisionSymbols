Add data sources to the chart, then set how each one is drawn here.
Range to the next source shades between this source and the one after it, for a minimum and maximum pair; the next source is not drawn on its own. State bands shades the chart's background by a digital tag's state, in the colours under State bands below. Avg adds a moving average, over a count of values (20) or a time (1h). Fit adds a straight-line fit.
A row marked No data source is kept as written and applies if a source is added at that position.
One entry per data source, comma separated: index:type[:axis][:#colour].
index counts the data sources in the order they were added (1 = first).
type is line, area, bar, step, scatter, range (shades to the next source), states (background bands by state) or hidden.
axis is left or right.
colour is a hex value such as #8267b0.
A line or step can also be dashed or dotted and take a width such as 1px.
Add ma20 or ma1h for a moving average over 20 values or one hour, and fit for a straight-line fit.
Example: 1:bar, 2:line:right, 3:line:#5aa0d6:dashed:1px:ma1h:fit. Anything not listed uses the default type on the left axis.
Bars that share an axis stack instead of standing side by side.
Decides how many time slots the bars are aggregated into: each slot is made wide enough that every bar inside it reaches this width. Lowering it gives more, narrower slots — finer time resolution, but below about 3px the bars stop reading as bars. Raising it gives fewer, chunkier bars. Grouped bar traces share a slot, so adding a bar trace reduces the number of slots at the same width; stacked bars share one column and so keep their resolution.
One panel per trace stacks a strip for each trace, each with its own scale, over one time axis: for tags whose units have nothing in common. Limit bands go on every panel whose trace is on the left axis.

A logarithmic scale cannot show zero or a negative value; the footer counts any it leaves out.
Limit bands
On the left axis. Each band shades from its own limit up to the next one, and the top band runs to the top of the axis. A limit belongs to the axis, not to a tag, so it costs no data source.
State bands
For a trace drawn as State bands: the colour of each state. A state not listed gets a colour of its own.
Rulers
Click the chart to place ruler A and again for B; drag either to move it. A table under the chart gives each trace's value at both, the change, and the minimum, maximum, time-weighted average, standard deviation, count and trend between them. Rulers are not saved with the display and do nothing while it is being edited.
Event frames
Shades each AF event frame in the window behind the traces, with its name along the top and its times on hover. Read through PI Web API, so it needs the site's pvx-config.js to reach it; the footer says what is missing if it cannot.
The display's asset is the one in its address, else the element of the first data source. Its events follow an asset swap.
