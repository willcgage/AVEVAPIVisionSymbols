Data sources
First is the X axis (usually inlet flow), second the Y axis (usually polytropic head, as an AF analysis). An optional third is a string attribute holding the curve spec, so each compressor's map follows the asset when the display is switched to another machine.
Each Y sample is paired with the X value in force at that instant; older than this and the pair is dropped. 0 means no limit.
Curves
One curve per line (or separated by |): name: x:y x:y ..., copied off the vendor map in the same units as the data sources. surge, control and stonewall are reserved; any other name is a speed line labelled with that name.
Draws a control line this far right of the surge line when the spec has no control curve. Use your anti-surge controller's setting. 0 draws none.
Surge margin
Margin = (flow − surge-line flow at the current head) ÷ surge-line flow. If your anti-surge controller publishes its own margin, that is the authoritative number.

Points
The trail fades from old to new so the direction of travel shows. Points outside the map are drawn at its edge and counted in the footer.
Axes
Blank bounds frame the map, or the data when there is no map.
