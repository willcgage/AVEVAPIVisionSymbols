Table
A table from the database's Library, under Tables, static or linked to an external source; AF does the linking and this only reads. It is read through PI Web API. Leave the database blank to use the database of the attribute dropped on this symbol, or of the display's asset. If the table name is wrong, the symbol lists the tables the database has.
Columns
Separated by commas or lines. Name | Header shows a column under another heading. A name the table does not have is named in the footer.
Rows
One per line, every one must hold: Column op value with = <> < <= > >=, contains, starts or in A, B, C. Numbers compare as numbers, text without case. {asset} is the name of the display's asset, so one display shared by several units shows each unit's rows.
A click on a heading sorts by it for that viewer; the saved order stays.
Color
Threshold bands
A bar down the left of each cell in its band's color. No bands, no color.
Click and download
{Column} is the row's value in that column. The asset column, when set, is passed as asset=.
