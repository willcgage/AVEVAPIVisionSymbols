Headline
Over the display's time range. Time-weighted counts each value for as long as it held, which plot values need: they crowd into the changes. Total over time integrates a rate, so a flow in t/h over a shift gives tonnes. Percent good is the share of samples that were good numbers, not a system state.
Trend indicator
Compared with the plan, a headline within this much of it, either side, reads On target in the good colour with no arrow. An amount is in the KPI's units; 2% is of the plan.
Plan compares the headline with the plan, reduced by the same statistic. As data source 2, drop the plan or target attribute onto the card after the KPI itself. From AF, the KPI attribute's own Target limit trait is read through PI Web API once a minute, so a target changed in AF reaches every card at once; it draws as a level on the sparkline.
With Earlier in the time range: compares the latest value against the value that far back in the display's time range.
Progress
The headline as a share of the plan (above), measured from this value: 0 for production against a target, or a starting level. Green once the plan is reached in the good direction, or within the tolerance; red short of it; the accent colour when neither direction is good. The figure is shown too, since a full bar cannot tell 100% from 140%.
Sparkline
Draws data source 2 as a dashed line on the sparkline, on the same scale.
Secondary stats
Appearance
Colours the card's left edge with the headline's band, or with a multistate if one is set. Below the first band the edge stays plain, so a band list such as 95:#f2c230:Watch, 100:#e5484d:Alarm flags only off-target values. The placeholder bands never colour it.
