Each attribute gets one verdict, the worst that applies: Bad, Out of range, Stale, Flatlined. Only the attributes with a problem are listed; the rest are counted in the footer.
Measured from the newest archived event. A healthy tag that holds steady only archives once per compression maximum (eight hours by default), so set this above CompMax for the tags you watch, or list slow tags under Update overrides. 0 turns the stale check off.
A value that moves less than the tolerance counts as unchanged. The display's time range must be at least this long for the check to see a flat line. 0 hours turns the check off.
Attribute label: low..high, one per line or comma separated. PI Vision does not pass an attribute's Zero/Span to symbols, so spans are entered here. Labels must match exactly; an entry that matches nothing is reported in the footer.
Attribute label: minutes replaces the stale limit for one tag. 0 excludes the tag from the stale and flatline checks (lab results, daily totals); excluded tags are still counted in the footer.
