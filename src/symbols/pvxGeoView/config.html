Where the markers go
Each data source's AF element is looked up for these two attributes, in decimal degrees, through PI Web API, once a minute. A PI point has no element, so it needs the list instead.
One per line, Name | latitude | longitude in decimal degrees. The name is matched to a data source's label, its element's name or its element's path.
Every data source without a place is named in the footer.

Map
The map comes from a tile server your site names once, as map.tileUrl in pvx-config.js. Without one the markers sit on a latitude and longitude grid. Drag to move the map, use the wheel or + and − to zoom, and the frame button to show every marker again.
