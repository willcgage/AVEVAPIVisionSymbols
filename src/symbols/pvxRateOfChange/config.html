Rate
The window is the smoothing: a longer one steadies a noisy signal and shows a step later. A window ending at each time lags by half its length, and has no rate for the first window of the time range. The fitted line is steadier still on noise. PI stores a value only when it changes, so the value at each end of the window is read off the straight line between the recorded values around it, as PI interpolates.
Leave it at 0 for a compressed tag: a long gap there means the value held steady. Set it for a tag that is scanned at a fixed rate, where a gap means the feed stopped. A value that is not a good number always breaks the trace, and the footer counts them.
Rate limits
Rates in the unit chosen above, per second, minute, hour or day. Type a fall limit as a positive number: 3 means falling faster than 3 per minute. Past a limit the trace turns its color, and the footer says how long it stayed past it and how many times. With no limits set nothing is flagged, and the footer says so.
