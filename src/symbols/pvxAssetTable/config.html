Rows
Drop the attributes of several elements onto the table: each element becomes a row and each attribute a column. A PI point has no element, so it is listed under the table instead of shown.
Lists the child elements of the display's asset through PI Web API and reads the attributes named under Columns for each. Follows an asset swap to an area with a different number of units, which a fixed list of data sources cannot.
Used when the display was opened without an asset. Left blank, the element of the attribute dropped onto the table is the root.
Two elements with the same name show their parent as well, whichever you pick.
Columns
Format: Attribute | Header | Color | Show. Only the attribute is required. Leave the list empty to show every attribute in the order dropped. 
Discharge Pressure | Disch psig | 0:#2f9e5f:Normal, 1150:#c8452f:High
Vibration          | Vib        | 0:#2f9e5f:Normal, 4:#d99024:Watch, 6:#c8452f:Trip
Status             |            | states | label
Color: blank colors numbers by the table's threshold bands and states by its state map below; none, bands or states pick one; a band list gives the column limits of its own. Show: value (default), label (the band or state label), or both.
Color
The dot takes the color of the row's worst cell: the highest band it has reached, or the state whose severity is highest. Its tooltip names the column.
Threshold bands (columns colored by bands)
No bands, no color: a table with no limits set flags nothing.
Digital state map (columns colored by states)

Interaction
The row's element is passed as asset=, so an asset-relative display opens on that unit. The display id is the number after /Displays/ in its address. Rows are keyboard reachable and open with Enter or Space.
Writing values
A click on a cell that writes opens a box under the table with its value; the new value is stated in full and confirmed, then written through PI Web API at the current time. There is no undo: the old value stays in PI's history. Numbers are checked as numbers, True/False is a choice, and anything else (a digital state's name, a string attribute) is sent as typed. Name columns by header or attribute, separated by commas. PI Web API decides who may write; its reason is shown when it refuses. Proven against a mock PI Web API only.
