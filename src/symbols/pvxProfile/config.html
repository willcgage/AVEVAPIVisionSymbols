Computed by PI Vision over the display's time range, one number per data source.
Position axis
Data sources arrive in whatever order they were dropped, which is often alphabetical — so Zone10 lands before Zone2. "Number in the name" reads a number out of each attribute name and sorts on it. "Manual positions" puts each point at a true physical distance.
Regular expression; the first capture group is the position. The default takes the last number in the name, so KILN1.ZONE07.TEMP gives 7.
One number per data source, in the order they are listed. Uneven spacing is drawn unevenly, which is the point.
Line and points
Smoothing interpolates between positions that were never measured, and can overshoot where two positions sit close together. Use "Straight" when the exact readings matter more than the sweep.
Each point takes its threshold band colour; the line keeps its own colour so the shape stays readable.
Reference profile
A faded second profile from a different statistic over the same window — typically the average behind the current value. Drift then shows up as a change of shape, not just of level.
Same as the charted statistic — the reference profile is hidden until they differ.
Limits
Both limits shade a band; one limit alone draws a single line. Points outside are ringed and recoloured.
Labels
Value labels are thinned automatically so they never overlap.
