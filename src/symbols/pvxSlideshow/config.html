Put this symbol on every display in the rotation, with this same configuration.
Navigating away destroys the symbol along with the rest of the display, so one copy on one display cannot keep a rotation running — it would jump once and then no longer exist. Each copy reads the current display out of the address bar, finds its own place in the list below, and schedules the next jump. Nothing changes per display: copy the symbol onto each display in the list, or paste the same settings in, and the rotation works.
Rotation
The master switch. Turn it off to stop the rotation on every display at once without deleting the symbol. The operator's previous / next buttons still work.
Format: display | label | dwellSeconds
Only display is required. label is the name shown on screen (left blank, it is taken from the display's own URL). dwellSeconds overrides the default dwell for that one entry — useful for a busy overview that deserves longer than the rest. Blank lines are ignored, and a line starting with # is a comment, so a display can be dropped out of the rotation for a shift without losing the line. 
101 | Plant Overview | 60
102 | Boilers
/Displays/103/Turbine-Hall | Turbines | 20
# 104 | Out of service this week
Finding a display id: open the display and look at the address bar. The id is the number straight after /Displays/ — in .../PIVision/#/Displays/101/Plant-Overview the id is 101. The name after it is cosmetic and is ignored when matching, so a renamed display does not fall out of the rotation.
Used for every entry that does not carry its own dwell.
When this display is not in the list
Applies when the display this symbol is on is not one of the entries above — somebody navigated somewhere by hand, or the display was taken out of the list.
Stay put — do nothing at all. The safest choice, and the default: an operator who went somewhere deliberately is never yanked away.
Go to the first entry — after the default dwell, jump to entry 1.
Pick the rotation back up — after the default dwell, jump to the entry after the last one the rotation actually visited in this browser session, falling back to entry 1 when there is nothing to remember.
Pausing
Any mouse movement, key press, scroll or touch anywhere on the page pauses the rotation. A display that navigates away while somebody is reading it is worse than no rotation at all. The symbol's own buttons do not count.
How long the screen must be left alone before the rotation carries on. 0 means it stays paused until somebody presses Resume.
Pausing is remembered for the whole browser tab, not just this display, so a pause survives the rotation moving on and the copy on the next display stays put too. It is forgotten when the browser session ends. Pressing Resume clears both a manual pause and the idle timer.
What travels to the next display
Leave the asset off unless every display in the rotation is built on the same AF template — carrying an asset to a display that cannot use it leaves that display blank.
Appearance
Previous, pause / resume and next. On hover they also appear when tabbed to, so they are still reachable on a screen with no mouse.
Below about 160×60 only the countdown and the position are drawn, and below 100×40 only the countdown — the words would be unreadable at those sizes.
Tighter spacing and no title, for a slim strip along the edge of a display.
Notes
The rotation never runs while a display is being edited, so a display cannot navigate out from under you while you are working on it. The symbol says so on screen while that is the case.
An entry that resolves to the display you are already on is skipped rather than reloaded, so a display listed twice does not cause a visible refresh.
