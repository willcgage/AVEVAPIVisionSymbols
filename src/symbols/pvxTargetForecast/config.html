Roles
Pick each role by name, or leave it automatic: the first data source is the actual, then the target, then the forecast. The forecast range is drawn as a band between two more sources, such as a P10 and a P90, and is never chosen automatically. Sources given no role are counted in the footer. Removing a picked source sets its role back to automatic.
Target
Read through PI Web API from the actual attribute's Target limit trait, once a minute, so a change made in AF reaches every display. A PI point has no traits.
A plan or setpoint is in force until it is changed, so the target is drawn as steps and the latest one is held to the end of the time axis. Clear this for a target that ramps between its values, such as a production curve.
A band around the target. The gap tile then says whether the actual is in or out of tolerance; with none it gives the gap alone.
Forecast
PI Vision sends a symbol the display's time range and nothing after it, so on a display ending at now the forecast stops at now. Either end the display in the future (an end time such as *+8h), and PI Vision sends the future values itself, or set a length here: the symbol then reads the forecast, its range and a target data source past the display's end through PI Web API, at most once a minute, and extends the time axis to cover it. It needs ext/libraries/pvx/pvx-config.js and does nothing on a display that ends before now.
Drawn fainter, so a forecast that was wrong earlier stays visible beside what actually happened. The forecast error tile compares the two either way.
Statistics
Actual and target at the latest actual value, the gap between them, the forecast where it ends with the time it first crosses the target, and the forecast error so far: the mean absolute difference from the actual where both exist, and its bias. Tiles that do not fit are left off, the gap last.
Text
The words used in the legend, the tiles and the readings, for example Plan, Budget or Nomination in place of Target. Blank keeps the word shown.
Color
Left on the theme, the actual is blue, the target follows the text color, the forecast is orange and the tolerance band green. The forecast range takes the forecast's color.
