Exceptions
Rows are scored by comparing each attribute's live value against the threshold bands configured below, and a digital tag by the band its state is put in under Digital states. This is not a PI Notifications or AF Event Frames client — there is no acknowledgement and no priority behind it. History mode reads past excursions from recorded values.
With Bands + data quality, an attribute PI Vision cannot read is listed above every deviation and always shown, whatever the minimum band.
Band index into the threshold list, counting from 0 at the lowest limit. 0 lists everything including Normal; 1 hides the first band, which is the usual "only show me deviations" setting.
How far below its limit a value must fall before it leaves a band: 2 in the attribute's units, or 2% of the limit. It stops a value sitting on a limit raising and clearing on every update. Blank means none.
Layout
List stacks the active exceptions vertically. Ticker scrolls them through a single line and pauses on hover. Summary shows one pill per band; it counts every attribute, ignoring the minimum band above. History lists each past excursion in the display's time range, newest first, with when it started and ended, how long it lasted and the highest value it reached, from recorded values read through PI Web API.
Row columns
Duration counts from the moment this browser first saw the attribute in its current band, and restarts when it moves to another band. It resets when the display is reopened, because PI Vision supplies current values only.
Columns drop themselves as the symbol narrows: duration first, then the band label, then units.
Motion
Rows already on screen when the display opens never pulse. If the operator's system asks for reduced motion, the ticker steps between items instead of scrolling and pulses are suppressed.

Click behaviour
Display id, id/name, or a full URL. The element the clicked row's attribute belongs to is passed as ?asset=, so an element-relative display opens on the right equipment. A PI point keeps the current asset.
Appearance
Threshold bands
Band order is the severity — the band with the highest limit is the worst.
Digital states
For digital tags: put each state in a threshold band, and it is listed and sorted exactly as a value in that band would. A state not listed here is never an exception.
