What to replay
PI time: *-1d, y+6h, 2026-10-27 03:00. Relative times are fixed when Play is pressed, so the replay does not drift while it runs.
Lengths of time: 30m, 1h, 1h 30m, 2d. At each step every symbol on the display shows the window ending at that moment, so trends scroll and values read as they were then.
Each step reloads the display's data from the archive. One second is the least; a display with many symbols or long windows wants more, or steps arrive before the last one has loaded.
Controls
With the symbol focused, Space plays and pauses, the arrow keys step, and Home and End jump. Changing the time any other way pauses the replay. Exit returns to the range shown before it. Nothing about the replay is saved with the display.
