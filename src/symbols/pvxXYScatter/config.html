Data sources
The first data source is the X axis, the second is the Y axis, and in bubble mode the third sets each point's size. Any further data sources are ignored. Drag the attributes onto the symbol in that order, or reorder them in the display's data source list.
Each Y sample is paired with the X value in force at that instant. If the newest X sample is older than this, the pair is dropped rather than plotted against stale data. Use 0 for no limit.
Axes
Blank bounds scale to the data (and to the envelope, when one is shown).
Points
Time shades points along the sequential ramp with a legend key. Threshold uses the bands below.
Turns the plot into a phase portrait — useful for start-up and batch trajectories.
Bubble area grows with the third source's value, paired by time the same way as X. Point size above is not used. The footer gives the value range the sizes cover.
Above 4,000 paired points the plot is uniformly subsampled; the footer says so.
Regression
Fitted on all paired samples, not just the drawn ones.
Operating envelope
Points outside the dashed box are drawn in the alarm colour. Blank bounds are unbounded on that side.
