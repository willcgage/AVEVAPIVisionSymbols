Data sources
The first data source is the X axis, the second is the Y axis, and in bubble mode the third sets each point's size. Further data sources are ignored unless Y is every source after X, or one is the gate. Drag the attributes onto the symbol in that order, or reorder them in the display's data source list.
Each Y source draws in its own color with its own fit, named in a legend. In bubble mode the third source still sets the size, and the gate source is never plotted. Color by time or by threshold colors every series alike.
Each Y sample is paired with the X value in force at that instant. If the newest X sample is older than this, the pair is dropped rather than plotted against stale data. Use 0 for no limit.
A gate keeps only the points taken while another source was in a range, such as speed at least 1000 for "while running". Its value is paired by time like X. The points left out are counted under the plot, apart from those with no gate value.

Turns the plot into a phase portrait — useful for start-up and batch trajectories.
Bubble area grows with the third source's value, paired by time the same way as X. Point size above is not used. The footer gives the value range the sizes cover.
Above 4,000 paired points the plot is uniformly subsampled; the footer says so.
Regression
Fitted on all paired samples, not just the drawn ones.
Operating envelope
In order around the shape; the last joins back to the first. A pump's or a compressor's allowed region is rarely a box. A corner not written as x,y is named under the plot.
Points outside the dashed envelope are drawn in the alarm color and counted under the plot. Blank box bounds are unbounded on that side.
