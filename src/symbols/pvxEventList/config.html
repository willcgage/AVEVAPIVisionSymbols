Event source
This symbol reads Event Frames from PI Web API, not from PI Vision's own data pipeline. Leave the database blank to use the database of the attribute dropped on it, or of the display's asset. If the symbol says it cannot reach PI Web API, open ext/piwebapi-check.html, which says what to change.
The asset is the one in the display's URL, or else the element of the attribute this symbol was placed with. Below the asset, each element is one sub-request in a single batch, and the footer says when the element limit cut the search short.
* and ? wildcards, as in PI Web API. These are applied by PI Web API before anything comes back; the filter box above the table only hides rows already read.
Overlapped includes the event that started before the time range and is still active, which is usually the one an operator is looking for.
The footer says when more events matched than were read. The list also re-reads whenever the display's time range or asset changes.
Time range
Used only when the display's URL carries no time range; the display's own time bar wins. Each row shows the event's whole duration, not only the part inside the time range.
Columns
name, element (the asset), template, start, end and duration, in any order. Any other word is the name of an event attribute, for example name, Reason Code, Operator, duration. Attribute values are read in one batched request; an attribute no event has is named in the footer.
Rows
The filter keeps the rows whose text contains it, in any column, without case. What an operator types in the box is not saved with the display.
Any column word from the list above. Operators can click a column heading to sort by it, and again to reverse; that is not saved either.
Groups and totals
Events with no value go in an (unassigned) group, last, rather than being left out.
A count and the summed duration per group and for the list. The total is the sum of the durations listed, so where events overlap it counts the overlap twice; the footer says by how much. PVX Event Analytics merges overlaps and clips to the time range, for a downtime total. Attribute totals are taken over the numeric values only.
Click
The time range is the event's, with a little either side. The asset is the event's primary referenced element.
