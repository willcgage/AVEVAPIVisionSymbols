Data
One data source is charted. Others may sit beside it as the source of its limits or specification, below.
The run rules assume evenly spaced samples. PI stores a value only when it changes, so by default the recorded values are time-weighted onto an even grid. Choose Recorded only for a tag sampled at a fixed rate with compression off, such as a lab result entered once per batch.
Chart
X-bar charts group consecutive samples. Use the range chart up to about 8 per subgroup and the standard deviation chart above that, where the range wastes information.
The strip shares the value axis and carries the normal curve the limits assume. It appears once the symbol is wide enough to keep the chart readable.
Control limits
Read from the limit traits of the charted attribute through PI Web API, so a limit changed in AF reaches every display at once. The Target trait is the centre line; without one, the centre is midway between the two limits. Re-read every minute.
Limits recomputed from everything shown. Good for a first look; a sustained shift then pulls the limits along with it, so the chart under-reports it.
Limits come from the first plotted points only, so everything after is judged against a known period. Set the display's start time on a stretch of normal running. At least 20 to 25 points give limits worth trusting.
Limits held as AF attributes or PI tags follow a grade or recipe change without anyone editing the display. The latest value of each source in the time range is used. With no lower limit it mirrors the upper one about the centre line.
Run rules
1: a point beyond the limits. 2: a run on one side of the centre line (9 by Nelson, 8 by Western Electric). 3: six points steadily rising or falling. 4: fourteen points alternating. 5: two of three beyond 2 sigma on one side. 6: four of five beyond 1 sigma on one side. 7: fifteen points within 1 sigma. 8: eight points beyond 1 sigma on either side. Every extra rule finds smaller shifts sooner and also raises false alarms, which is why Western Electric uses four.
Red marks a point beyond the limits, amber any other rule. Hover a point for the rules it breaks. Rules are evaluated while the display is open; nothing is written to PI or AF.
Specification
A trait the attribute has replaces the value above; one it lacks leaves the typed value. The Target trait, when there is one, is the target.
Control limits are what the process does; spec limits are what the customer needs. Cpk uses the within-subgroup sigma and Ppk the overall one, so a Ppk well below Cpk says the process drifts between subgroups. Leave one limit blank for a one-sided specification.
