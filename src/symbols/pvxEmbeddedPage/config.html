Page
A number, or 101/Overview, is a PI Vision display on this server and always shows. Any other http or https address shows only if that site allows framing; many do not, and the browser then leaves the frame blank without saying why, so the symbol says it under any page from another site and offers Open in a new tab. With the data source chosen, an AF attribute holding the address drives it, so an asset swap changes the page.
These three apply to PI Vision displays only. The display inside follows this one when its asset or time changes.
Behaviour
0 never reloads. For a page that does not update itself, such as a report or a camera still. Shortest 15 seconds.
Below 100 fits a whole page into a small symbol.
Stops the page from navigating this display or opening downloads. Some pages will not run restricted.
