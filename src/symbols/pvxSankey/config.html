Flow
Ribbon thickness is proportional to this number. Everything except Current value is calculated by PI Vision over the display's time range. For a balance over a shift or a day, Total is usually the honest choice; Current value shows the flow right now.
Topology
Read this first. The PI System has no graph structure to read. A tag knows its own value; it does not know what it flows into. Nothing on the server records that the boiler feeds the turbine. So the topology has to be written here, by somebody who knows the process. That makes this symbol excellent for a fixed, well-understood plant area — and the wrong tool for an ad-hoc set of tags.
One link per entry, entries separated by |:
From > To : sourceIndex
sourceIndex is the 1-based position of the data source in the list above that supplies the magnitude — data source 1 is the first attribute dropped on the symbol. Spaces around every token are ignored.
Worked example. A reactor fed by one stream, producing product and venting the rest. Drop three attributes on the symbol: 1 feed flow, 2 product flow, 3 vent flow. Then write:
Feed > Reactor : 1 | Reactor > Product : 2 | Reactor > Vent : 3
Feed appears only as a source, so it is drawn as a source node on the left. Product and Vent appear only as targets, so they are sinks on the right. Reactor is in the middle, and its inflow and outflow are compared — see Balance below. Add Vent to Loss / vent nodes to draw it in the alarm colour.
Node names are free text and are matched exactly, so Reactor and reactor are two different nodes. A cycle (a node that ends up feeding itself, directly or through others) has no left-to-right order, so the link that closes it is dropped and named in the footer. Malformed entries, missing data sources and zero or negative flows are all reported there too, never silently discarded.
With Links empty, the first data source is drawn flowing into a hub and every other source branches off it. It is a placeholder so a freshly dropped symbol is not born blank — it is not your process, and the footer says so on every frame until you write real links. Balance is not checked under the automatic layout: "these two numbers should have been equal" is a claim about the plant, and only you can make it. Anything you type in Links, even a typo, switches the automatic layout off so a mistake is never hidden behind a picture that looks fine.
Links below this are dropped and counted in the footer. Useful for hiding sub-percent streams that would otherwise be a hairline nobody can read.
Balance
A node whose inflow and outflow differ by more than this is outlined in the alarm colour, flagged with a dot and named in the footer. That difference is real information: a leak, a mis-scaled meter, or a stream nobody has tagged yet. Only nodes with both an inflow and an outflow are checked — a source has nothing coming in and a sink has nothing going out, so neither can be out of balance.
Comma separated node names, drawn in the alarm colour. Use it for the streams that represent throughput you are paying for and not keeping.
Colour
Source node lets you follow one stream with your eye from where it came from to where it ends up. Gradient shows a stream visibly becoming what it turns into. Threshold band colours each ribbon by its own value, which reads as a rate rather than as a route.
NodeName:#colour, comma separated. For the handful of nodes that need to be a specific colour — a loss stream in red, the saleable product in green. Everything else takes a palette colour.
Ribbons overlap where streams cross. Below about 0.6 the overlaps read as shading rather than as a solid block, which is what makes a busy diagram legible. Flows whose source reports bad quality are always drawn hatched, whatever the colour mode.
Labels
Outside puts the first rank's names before the diagram and the last rank's after it, which reads like the headings of a table but costs margin. Against the node keeps every pixel for the ribbons. Names in the middle of the diagram always sit just above their node — there is no margin there to use.
Every name is measured against the room it actually has and truncated with an ellipsis; the full string is always in the tooltip. Below roughly 240×160 pixels the names and values are dropped, and below 140×100 only the ribbons are drawn.
Units are shown only where every flow touching that node agrees on them — a node fed in kg/h and drained in MW has no single unit to print.
Geometry
The gap is a nicety and the ribbons are the message, so it is capped automatically when a rank has too many nodes to fit it.
0 draws straight ribbons, 0.5 is the usual S-curve, 1 leaves each end horizontal for as long as possible.
