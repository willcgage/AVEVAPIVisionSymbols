Assets
This symbol finds its assets with an AF search through PI Web API, not through PI Vision's own data pipeline, so an area that gains a unit next year needs no display edit. The search starts at the display's asset. If the symbol says it cannot reach PI Web API, open ext/piwebapi-check.html, which says what to change.
Used when the display was opened without an asset. Left blank, the element of the attribute dropped onto the symbol is the root.
The footer says when the limit cut the search short. Each refresh reads every asset's value in one batch request.
Roll-up
The attribute's name on each asset, such as Production Rate, or a relative path such as Motor|Current. Assets without it are counted in the footer.
Blank counts every asset with a value. A digital state is compared by its name, ignoring case; a number by its value. Several values separated by commas count any of them.
Cards
Others is worked out from its own assets, not by adding up the cards it replaces, so an average stays an average. Without it the footer says how many groups are hidden.
Colour
Threshold bands
Bands win over the target when both are set. With neither, no card is coloured: a roll-up with no limits set flags nothing.
Click
A card per parent element passes that element as asset=, so an asset-relative display opens on it.
