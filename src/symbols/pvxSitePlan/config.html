Background image
This is the offline-friendly alternative to a geographic map. Most plant networks cannot reach a map tile provider, so a map symbol renders as an empty grey grid — and for a single site a scaled plant drawing, P&ID, single-line diagram or equipment photo is more useful than a satellite view anyway: operators navigate by “the north cooling tower”, not by latitude.
Absolute or relative — the file must be reachable from the browser, not from the PI Vision server. The reliable option is to drop the image in PI Vision's ext folder alongside this symbol and reference it by a relative path, so it is served by the same site and needs no extra firewall rule. External hosts (SharePoint, a CDN, another intranet server) are often blocked on a plant network or fail on mixed content. If the image does not load, the symbol falls back to the labelled placeholder grid and says so in the footer.
Hotspots are positioned relative to the image, so they stay on the same features whichever fit is used. With Cover the edges of the image are cropped, and any hotspot in the cropped strip is counted in the footer rather than silently disappearing.
Draining the colour out of a busy drawing makes the coloured markers pop. Worth turning on for scanned P&IDs and photographs.
Hotspots
One entry per data source, in the same order as the data sources are listed. Each entry is x,y or x,y:Label, and entries are separated by | — the coordinate pair already uses a comma, so a comma cannot also separate the entries.
x and y are percentages of the image (0,0 is top-left, 100,100 is bottom-right), never pixels: pixel coordinates would break the moment somebody resized the display or swapped in a higher-resolution scan. Values outside 0–100 are clamped to the edge and counted in the footer.
Leave an entry empty to skip a source — 12,44 | | 80,72 pins the first and third. A label typed here is always shown; Show names only controls whether the data source name is used when no label was typed.
Sources with no entry are auto-placed on a grid in an unused part of the drawing, drawn slightly faded, and named in the footer, so nothing is ever silently invisible. To position them, read the coordinates off the placeholder grid's percentage ruler (visible until an image is set).
Markers
A pin points at its coordinate; the other shapes are centred on it.
Sizes are screen pixels and do not scale with the image: a marker stays the same physical size whether the symbol is a small tile or a wall display. Below roughly 200×140 markers shrink and labels are dropped; below 140×100 only the markers remain.
Colour
Bad quality always wins: the marker keeps its colour but is drawn hollow, because a stale tag's last value is often still inside a “normal” band.
Threshold bands
State:colour or State:colour:label, comma separated. Matching is exact and case-insensitive, e.g. Running:#2f9e5f, Fault:#c8452f. A numeric tag mixed into a digital plan falls back to the threshold bands.
Labels
Everything except Current value is calculated by PI Vision over the display's time range.
Overlapping labels are moved to the next free side, worst band first, so the marker that matters keeps the position you asked for. A label with nowhere to go is dropped — its value is still in the marker's tooltip.
Essential over a busy drawing; bare text on a scan is unreadable.
Draws a line to any label that had to move, so it is still obvious which marker it belongs to.
Alarm emphasis
Markers in the highest threshold band get a pulsing halo. The motion is suppressed for viewers who have asked their operating system to reduce motion; the halo stays.
Interaction
Open the target display and copy the number after /Displays/ in its address bar — in .../#/Displays/142/Pump-Detail the id is 142. The clicked marker's asset path is passed through as the asset= parameter, so an asset-relative display switches to that tag's element. Leave blank to re-target the current display. Markers are keyboard reachable and activate with Enter or Space.
