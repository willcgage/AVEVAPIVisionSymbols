What sounds
A tone made in the browser when a data source goes into alarm, repeated until it is silenced, acknowledged or clears. No sound files, and nothing to change on the server. Browsers need one click on the symbol before a page may make sound, so it says Click to turn alarm sound on each time the display opens.
Threshold bands
Digital states
The same bands as the Annunciator and the Exception Banner: copy them across and the tone sounds for exactly what those show.
Band index, counting from 0. With bands Normal, High, Critical, 1 sounds for High and Critical, 2 for Critical only.
How far below its limit a value must fall before the alarm counts as clear: 2 in the source's units, or 2% of the limit. Without one, a value sitting on a limit starts a new alarm, and a new tone, again and again.
Tone
A different tone while anything sounding is in the highest band, so Critical can be told from High without looking.
0 plays once for each new alarm.
Alarms already in force when the display opens. Off, only alarms that start afterwards sound. With shared acknowledgements on, standing alarms already acknowledged stay quiet either way.
Silencing
Clicking the symbol while it sounds silences it on this screen only; it does not acknowledge anything. With shared acknowledgements on, an acknowledgement made on an Annunciator that uses the same AF attribute silences every screen. This symbol only reads that attribute; it never writes to it.
Needs PI Web API. Give this symbol the same data sources as the Annunciator, so each alarm is known by the same name in both.
