Positions
One data source per position across the sheet, web, kiln or stack. The map runs across in position order and down in time, newest at the top.
By number puts "Gauge 10" after "Gauge 9", whatever order they were added in. A name with no number goes last, and the footer says how many.
Rows in the map, each the average of the values in its interval. An interval with none holds the last value, as a scanner's profile does between scans.
Colour
Blue below the target, red above, white on it. Set the span to the tolerance and anything fully coloured is out of it.
Profile
The band is how far each position wanders over the time range. The footer gives the 2-sigma across the current profile and the average 2-sigma along time at one position.
