Interaction
Open the target display and copy the number after /Displays/ in its address bar — in .../#/Displays/142/Pump-Detail the id is 142. The element the clicked tile's attribute belongs to is passed as the asset= parameter, so an asset-relative display switches to that element. A PI point has no element, so its tile keeps the current asset. Leave blank to re-target the current display. Tiles are keyboard reachable and activate with Enter or Space.
