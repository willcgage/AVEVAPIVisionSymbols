Size
Tile area is proportional to this number. Everything except Current value is calculated by PI Vision over the display's time range. Zero and negative values cannot be drawn as an area, so they are excluded and named in the footer.
Grouping
Parent asset in AF groups each tile under the element one level above its own, which with rows from an AF search is the plant's own hierarchy. PI returns a flat list, so otherwise the hierarchy has to come out of the AF path or the tag name. Groups are laid out first, then the tags inside each group, and each group gets a header strip with its name and total.
Depth 1 is the first segment after the server name. A path shorter than this groups on its last real segment rather than falling into "Ungrouped".
Used by Name prefix: tags whose names start with the same N characters share a group.
Colour
Size shows who is big, colour shows who is in trouble. Threshold band colours by the same statistic the tiles are sized by, which is the combination worth reading. With rows from an AF search naming two attributes, the first sizes the tiles and the second colours them (load by efficiency, say), paired by asset. Palette and Group identify rather than rank, so they carry no legend of magnitude.
Tiles whose source reports bad quality are always drawn hatched, whatever the colour mode, and keep their share of the area.
Readability
Tiles smaller than this get no label. Below half of it they are combined into one tile: a treemap of unreadable slivers is worse than an honest aggregate.
Labels
Labels are measured against their own tile. When a tile is too short the value line is dropped first, then the name is truncated, then the label is dropped entirely.
Tiles
Interaction
With grouping on, a click on a tile shows only its group, filling the symbol, with a trail above to go back. Inside a group a click opens the target display, as Open a display does.
The clicked tile's asset path is passed through as the asset parameter, so one detail display serves every tile. Leave the target blank to stay on this display and just switch asset. The combined tile stands for several assets, so it never navigates.
