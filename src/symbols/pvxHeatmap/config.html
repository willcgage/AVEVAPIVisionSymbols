Grid
Calendar uses the first data source only: rows are the hour of day, columns are calendar days. Matrix gives every data source a row and splits the display's time range into equal columns. Density uses the first data source: rows are bins of its value, and each cell is the share of that time slice the tag spent there, weighted by time rather than by sample count.
Matrix and density modes. Reduced automatically if rows × buckets would exceed 2000 cells.
Fix the value axis to the instrument range or the operating limits so two periods are comparable. Time spent outside it is reported in the footer, not piled into the edge rows.

Colour scale
Sequential for magnitudes, diverging for deviation from a target, threshold bands for discrete states (no blending between colours).
Leave blank to fit the scale to the data. Fix both to compare two heatmaps side by side.
Threshold bands
Used when the scale is set to threshold bands.
Legend
The legend is dropped automatically when the symbol is too small to keep a readable grid.
Cells
Only drawn where a cell is at least 28 × 16 px; text colour is contrast-matched to each cell.
Labels
Labels thin out automatically as the grid shrinks, so they never overlap. Hover any cell for the full row, column and value.
Appearance
Used for the hover outline on a cell.
